# mytombrown.com

Product site: one page per app, what it is and how to use it. Static HTML on
GitHub Pages (`CNAME` + `.github/workflows/pages.yml`), same style family as
legal.mytombrown.com. Registered as WEB-733 on the appops board.

- `/` — every app, one card each
- `/squishy-math/`, `/squishy-words/`, `/team-assist/`, `/srt-stream-tester/`, `/family-meal-planner/`, `/satellite-surface-remote/`
- `bash scripts/check-site.sh` — WEB-T-1: the live site answers and the Squishy Math page teaches the game

Screenshots come from each app repo's `docs/screenshots/`, resized to 900px JPEG with `sips`.
