How it works

Drop, pick a folder, start.

  1. Drop images in. Or browse for them.
  2. Pick a folder. The PNGs are saved there.
  3. Choose to replace or not. Turn on Replace existing files if you want.
  4. Tap Start. Each file shows when it's done.

Formats

Lots in, PNG out.

  • Reads JPG, PNG, GIF, BMP, TIFF, TGA, PSD, OpenEXR, WebP, HEIC and HEIF.
  • No resizing. Images stay the size they were.
  • Transparency is kept. Nothing is flattened.
  • Something failed? Reset Failed tries those files again.
