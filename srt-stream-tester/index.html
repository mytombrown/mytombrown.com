SRT Stream Tester

Send or receive an SRT stream and watch the link's health live. Caller or listener, either direction.

In development

How to use it

Set up, connect, read the numbers.

  1. Pick the handshake. Caller dials out to a listener. Listener waits for a caller.
  2. Pick the direction. Receive plays the incoming stream. Send pushes the camera and microphone.
  3. Enter the endpoint. Host and port for a caller. Port only for a listener.
  4. Set the options. Latency in ms, an optional passphrase, an optional stream ID.
  5. Connect. The video plays, the stats start, the event log fills in.
  6. Read the health line. One verdict on loss, latency versus round-trip time, and passphrase mismatch.

What it measures

Live link diagnostics, once a second.

  • Round-trip time and throughput, with charts.
  • Link bandwidth estimate.
  • Packet loss, retransmits, drops that arrived too late.
  • Undecrypted packets, which means the passphrase does not match.
  • Buffer levels and an event log you can copy.

Works with

Anything that speaks SRT.

  • OBS, ffmpeg, MediaMTX, hardware encoders and decoders.
  • Receive: MPEG-TS with H.264 or HEVC video and AAC audio, hardware decoded.
  • Send: camera and microphone as H.264, 480p to 1080p, 1 to 12 Mb/s.
  • Passphrase (AES) and stream ID supported.
  • iPad and Mac show setup in a sidebar with video, stats, charts and the log beside it.
