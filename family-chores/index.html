Family Chores

Kids do chores and earn points. Parents make the rewards. Everyone sees the same list.

How it works

Chores, points, rewards.

  1. Make a family. Add kids and parents. No device or Apple ID needed to add someone.
  2. Invite with a code. They type the 6-character code or scan the QR code.
  3. Add chores. Set the points, who does it, and how often.
  4. Kids mark it done. Some chores need a note or an amount, like 20 minutes.
  5. Parents approve. Turn approval on or off for each chore.
  6. Spend points. Kids pick a reward. Parents approve it.

Chores

Set it once.

  • Repeats: one time, daily, certain days, weekly, monthly, or every few days.
  • Each child does it, or they take turns.
  • Missed it? Skip it, keep it open, or move it to the next day.
  • Optional due time.

Points and rewards

Fair and clear.

  • One point balance per child.
  • Rewards can need approval, run out, or show only to some kids.
  • Every point is in the activity log: earned, spent, undone, or changed by a parent with a reason.
  • Shared over iCloud so every phone sees the same family.
